# Chase's Home Assistant add-ons

Add this repository in Home Assistant: **Settings → Add-ons → Add-on Store → ⋮ → Repositories** and paste
`https://github.com/nurtrino/home-assistant-addons`.

| Add-on | What it does |
|---|---|
| [Home News](home_news/) | Collects news feeds, ranks them with Claude, and publishes `sensor.home_news` for a TV welcome and dashboards. |
